# Database – RepoPulse

This folder contains the PostgreSQL database design and schema implementation for RepoPulse.

The database is designed using normalized relational modeling principles and supports features such as:
- repositories
- branches
- commits
- pull requests
- issues
- discussions
- releases
- notifications
- collaborators
- repository analytics

## Project

RepoPulse – DBMS Project
